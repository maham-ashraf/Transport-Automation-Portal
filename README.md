**Project Overview**

The University Transport Automation Portal is a web-based system developed to manage university transportation efficiently. It allows students, staff, and administration to handle transport-related operations such as route management, attendance, fee tracking, and registration.

**Objective**

The main objective of this project is to automate the manual transport system and provide a centralized platform for managing transport operations.

**Technologies Used**
Frontend: HTML, CSS, JavaScript
Backend: PHP (Core PHP)
Database: MySQL
Server: XAMPP (Apache + MySQL)

**Features**
User authentication (Login system)
Role-based dashboards (Admin, Student, Accounts, Focal Person)
Transport route management
Bus management system
Student registration system
Attendance tracking
Fee management system
Complaint and feedback system
